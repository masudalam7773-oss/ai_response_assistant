## AI Response Assistant — Python + Gemini

Built a Python-based AI Response Assistant using the Google Gemini API.

The application accepts user questions, generates AI responses, maintains conversation context, saves chat history, handles API and connection errors, and provides specialized assistant modes such as General Assistant, Python Tutor, Writing Assistant, and Summarizer.

### Technologies

* Python
* Google Gemini API
* Google GenAI SDK
* Git
* GitHub

### Key Skills Demonstrated

* Conversation management
